## 终审修复

所有下列问题均用失败用例或可重复的离线探针确认后修复。

| 编号 | 等级 | 问题与最终行为 |
|---|---|---|
| F01 | P1 | 累计成交量增加、累计名义倒退或溢出会生成非法增量价格；现在保留原订单身份与采纳水位，等待有效事实。 |
| F02 | P1 | 空或不可读的 pending/resting 契约被当作没有未决委托；现在保留成员、阻断新开仓及不安全接管。 |
| F03 | P1 | 冷恢复首仓序号与实时序号不一致，续成交丢掉已有费用池；现在统一按实际平仓事件推进。 |
| F04 | P1 | 平仓前最后一次盯市后跨资金费结算点，漏计末段费用；现在用缓存补齐末段且重复事件不重复结转。 |
| F05 | P1 | 仍有效但参数已变化的资金费快照漏过执行前检查；现在比较费率、周期、结算锚点及覆盖状态。 |
| F06 | P1 | 实时顶层 wallTs 尚未写入 explain 时，持仓时长被算为零；现在优先读取实际墙钟时间。 |
| F07 | P1 | 平仓后的可选学习异常中断同批后续成交；现在隔离异常，继续原始落库与事件派发。 |
| F08 | P2 | 撤销期间成交仍回报未成交，平仓成交标志也固定为 false；现在两个标志均取实际事件。 |
| F09 | P1 | 零仓位解被展示为模型自主观望；现在保存 sizingVerdict 和 factsHash，并由诊断与响应模型贯通读取。 |
| F10 | P2 | 不闭合漏斗仍显示百分比、结构化原因丢失、未知版本被按 v2 解释；现在停用不可信比例并保留原始原因和版本提示。 |
| F11 | P1 | 回测空仓预览固定多头，负资金费时低估空头成本；现在选取最高成本方向，持仓按真实方向。 |
| F12 | P2 | 回测持仓缺真实费用输入，精确回本价始终未知；现在传入模拟开仓费、币数、平仓费率及已发生资金费。 |
| F13 | P1 | 停止时原始平仓腿写入失败仍报成功，取消数据库等待也丢失重试入口；现在先登记稳定事件、停止重试、持久化 pendingTrades，并在冷预检前幂等补写。 |
| F14 | P1 | pendingTrades 清理失败或成交/恢复记录双重写入失败会丢失会话入口；现在失败回执保留待办、运行对象及新组阻断，重复停止只补写，不重复下单。 |

F13–F14 复用既有成员 JSON，无新表或交易端口。共享 `trade_persistence`
只处理原始成交的幂等写入；恢复补写不产生经验、下单或撤单副作用。
新增职责及相应测试属于 T34/T36/T41 的补漏。
